# Capstone

## 프로젝트 구성

### 펌웨어 (ESP32-S3)
보드별로 센서 값을 읽어 서버로 전송하는 아두이노 코드입니다.

**상체**

| 파일 | 설명 |
|---|---|
| `arm_left.ino` | 왼팔 ESP32-S3 보드 펌웨어 |
| `arm_right.ino` | 오른팔 ESP32-S3 보드 펌웨어 |
| `shoulder.ino` | 어깨 ESP32-S3 보드 펌웨어 |

**하체**

| 파일 | 설명 |
|---|---|
| `leg.ino` | 다리 ESP32-S3 보드 펌웨어 |
| `waist.ino` | 척추(허리) ESP32-S3 보드 펌웨어 |

### 서버
| 파일 | 설명 |
|---|---|
| `server_up.py` | 상체 보드(왼팔·오른팔·어깨)에서 전송된 데이터를 취합·처리하는 서버 코드 |
| `server_down.py` | 하체 보드(다리·척추)에서 전송된 데이터를 취합·처리하는 서버 코드 |

### 뷰어
| 파일 | 설명 |
|---|---|
| `pose_full.html` | 수집된 전신 자세 데이터를 3D로 시각화하는 웹 뷰어 |

## 시스템 구조

```
[왼팔]  [오른팔]  [어깨]        [다리]   [척추]
  │        │        │             │        │
  └────────┴────────┘             └────────┘
           │                           │
     server_up.py               server_down.py
           │                           │
           └─────────────┬─────────────┘
                          │
                    pose_full.html
                     (3D 뷰어)
```

각 ESP32-S3 보드가 관절/자세 센서 값을 측정하여 해당 서버(상체/하체)로 전송하면, 서버가 데이터를 수신·가공하고 `pose_full.html`이 이를 실시간 3D 전신 모델로 렌더링합니다.

## 사용 방법

1. `arm_left.ino`, `arm_right.ino`, `shoulder.ino`, `leg.ino`, `waist.ino`를 각 ESP32-S3 보드에 업로드합니다.
2. `server_up.py`, `server_down.py`를 실행하여 서버를 구동합니다.
3. `pose_full.html`을 브라우저에서 열어 실시간 전신 자세를 확인합니다.
